⚙️ 대시보드 설정

채팅 · 테마 · 타이머 · 개인정보 설정을 한 곳에서 정돈해요.

현재: px

레이아웃

작업 흐름에 맞춰 “메인 + 채팅”의 위치를 바꿀 수 있어요.

테마 선택

동그라미는 “배경(왼쪽) + 내 말풍선(오른쪽)” 반반 미리보기예요.

타이머 표시

타이머는 잔잔한 그라데이션 + “임박” 때만 살짝 강조돼요.

마감 분 이하면 강조가 들어가요.

내 데이터

개인 작업 영역(투두/메모/목표/오늘 누적)은 Firebase에 필명 기준으로 저장돼요.
필명이 같으면 덮어써질 수 있으니, 중복되지 않는 필명을 권장해요.

로컬 설정 초기화

테마/채팅 너비/레이아웃/타이머 표시 설정만 초기화돼요.

🕵️‍♀️ 관리자 모드가 발견됐어요. 로그인 후에만 버튼이 나타나요.

채팅 상단에 공지처럼 고정돼요. 모든 접속자에게 보여요.

🕘 이전 채팅 불러오기

내 화면에만 과거 대화를 불러와요. 다른 작가님들 화면에는 영향이 없어요.

📡 입장 히스토리 노출 설정

현재 적용 중: 불러오는 중…

📋 접속 기록 (최근 7일)

날짜별로 접속한 필명을 확인할 수 있어요. 7일이 지나면 자동 삭제돼요.

해당 필명이 모든 화면에서 업적 달성 상태로 보여요. 실제 출석 데이터는 바뀌지 않고, 24시간 후 자동 만료돼요. 필명을 비우고 해제하면 전체 해제.

주의: 되돌릴 수 없어요.
